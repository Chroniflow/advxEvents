# 响应式登录导航与退出设计

## 背景与目标

当前站点头部始终同时显示“我的轶事”和“GitHub 登录”，并通过移动端 CSS 隐藏 `.account-link`。因此手机用户登录后仍会看到登录按钮，却无法进入“我的”页面。Worker 已经提供 `/api/auth/me` 和 `POST /api/auth/logout`，但前端没有全站登录状态，也没有退出操作。

本次改造目标：

- 手机与桌面端都能根据真实登录状态展示正确导航；
- 登录后移除 GitHub 登录按钮，并显示稳定可见的“我的”入口；
- 在“我的”页面提供退出登录；
- 退出成功后跳转首页并立即恢复未登录导航；
- 退出失败时不伪造退出状态，并向用户显示错误。

## 方案选择

采用 App 层认证状态方案。`App` 在挂载时请求一次 `/api/auth/me`，将登录用户或匿名状态传给 `SiteHeader`，并通过 Outlet context 传给需要修改状态的账号页。

相比让 `SiteHeader` 与 `AccountPage` 分别请求登录状态，该方案避免重复请求和状态不一致。相比引入独立状态管理库，React 内置 state 与 React Router Outlet context 已足够，符合项目规模。

## 组件职责

### App

`App` 是认证状态的唯一前端来源：

- 初始状态为加载中；
- 请求 `/api/auth/me` 成功后保存 `UserProfile`；
- 收到 401 或其他失败时按匿名用户处理，头部展示登录入口；
- 向 `SiteHeader` 传递当前用户；
- 通过 Outlet context 暴露当前用户及更新函数，使退出成功后账号页可以清除全局状态。

本次不引入定时刷新、跨标签页同步或持久化前端用户数据。

### SiteHeader

未登录时：

- 显示 GitHub 登录按钮；
- 移动端使用现有 GitHub 图标按钮形式；
- 不显示“我的”入口。

已登录时：

- 不显示 GitHub 登录按钮；
- 显示指向 `/account` 的“我的”按钮；
- 桌面端显示“我的”文字；
- 移动端显示用户图标并提供可访问名称，不再隐藏整个入口；
- “投稿”按钮保持现有行为。

加载登录状态期间不显示登录或“我的”按钮，避免短暂显示错误操作；“投稿”仍保持可见。

### AccountPage

账号页继续加载用户投稿列表。全局用户状态用于确定页面已知登录状态，实际投稿数据仍通过 `/api/stories/mine` 获取。

已登录页面的操作区新增“退出登录”按钮：

1. 调用 `POST /api/auth/logout`；
2. 成功后清除 App 中的用户状态；
3. 使用客户端路由跳转到首页；
4. 头部立即恢复 GitHub 登录按钮。

退出请求进行中时禁用按钮，防止重复提交。

退出失败时：

- 保留当前用户状态；
- 保留当前页面；
- 在账号页操作区附近显示简体中文错误提示；
- 允许用户再次尝试。

直接访问 `/account` 且未登录时，继续显示“请先使用 GitHub 登录”和登录按钮。

## API 客户端

在现有 `api` 对象中增加：

```ts
logout: () => request<{ ok: true }>("/api/auth/logout", { method: "POST" })
```

不修改 Worker 接口。现有退出端点已经撤销 KV 会话并返回清除 Cookie 的响应头。

## 响应式样式

移除移动端对 `.account-link` 的整体隐藏。新增的“我的”入口使用稳定的 38×38 像素图标按钮尺寸，文字仅在窄屏隐藏，元素本身保持可见。

移动端头部保留三个区域：品牌、“登录或我的”入口、投稿按钮。按钮尺寸固定，状态切换不能导致头部高度或整体布局跳动。

退出按钮位于账号页操作区，不占用手机头部空间。

## 测试与验证

新增或扩展前端单元测试：

- 未登录 Header 显示 GitHub 登录，不显示“我的”；
- 已登录 Header 显示“我的”，不显示 GitHub 登录；
- 登录状态加载期间不显示两个认证入口；
- 退出成功调用正确 API、清除全局用户并跳转首页；
- 退出失败保留用户并显示错误；
- 移动端 CSS 不再隐藏“我的”入口，并维持固定图标按钮尺寸。

完成后执行：

```bash
npm test
npm run build
npx wrangler deploy --dry-run
```

使用 Playwright 或浏览器尺寸模拟检查桌面与手机宽度，确认头部按钮不重叠，登录状态切换后文案和图标正确。

## 非目标

- 不新增用户下拉菜单；
- 不在头部直接显示退出按钮；
- 不实现跨标签页登录状态同步；
- 不修改 GitHub OAuth、Session 或 Worker 权限模型；
- 不改变“投稿”按钮与账号投稿列表的业务行为。
